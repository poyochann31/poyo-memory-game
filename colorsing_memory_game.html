遊び方

  1. 「ゲームを始める」を押してスタート。
  2. カードを2枚ずつめくろう。
  3. 同じ絵柄が出たらペア成立！
  4. 違う絵柄ならカードは元に戻るよ。
  5. 15組すべてそろえたらクリア！

ランキングに参加するときは、毎回同じ名前で入力してね！
